{# A dd/mm/yyyy date field: EU-formatted text box + native calendar button. A native can't be told what format to DISPLAY (the DOM value is always ISO, and the rendering follows the browser/OS locale — Firefox and Safari ignore the document's `lang` entirely). So the control is a pair: * a visible text input the owner reads/types in dd/mm/yyyy — NOT named, so it never reaches the server; and * a hidden that carries the ISO value and IS the named field, keeping the server contract (`yyyy-mm-dd`, validated in the route) exactly as it was. static/eudate.js wires the two together and makes the button open the native calendar. Without JS the hidden input is revealed, so the filter still works. Params: name – submitted field name; label – visible label; value – ISO date string (or ""). #} {% macro datefield(name, label, value) %} {% endmacro %}
